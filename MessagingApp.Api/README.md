# MessagingApp.Api - Backend Servisi Calistirma Talimati

Bu proje, mesajlasma uygulamasinin veritabani baglantilarini yoneten ve istemcilere RESTful endpoint'ler sunan ASP.NET Core Web API katmanidir.

## Gereksinimler
- .NET SDK (8 veya uzeri)
- PostgreSQL Veritabani

## Calistirma Adimlari
1. PostgreSQL sunucusunun calistigindan emin olun.
2. Terminali bu klasorde acarak su komutu calistirin:
   ```bash
   dotnet run
   ```
3. Servis `http://localhost:5000` adresinde dinlemeye baslayacaktir.
4. Swagger test arayuzune tarayicinizdan erismek icin: `http://localhost:5000/swagger`

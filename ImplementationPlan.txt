Adım 1: Core Katmanı
Evrensel, hiçbir iş veya veri katmanına bağımlı olmayan çekirdek yapıların kodlanması:

Marker Interface'ler:
Core/Entities/IEntity.cs: Veritabanı tablolarını temsil eden sınıfların imza arayüzü.
Core/Entities/IDto.cs: Veri taşıma nesnelerini (DTO) temsil eden sınıfların imza arayüzü.
Generic Repository Altyapısı:
Core/DataAccess/IEntityRepository.cs: T : class, IEntity, new() kısıtıyla Get, GetAll, Add, Update, Delete CRUD imzaları.
Core/DataAccess/EntityFramework/EfEntityRepositoryBase.cs: Entity Framework Core kullanarak generic CRUD operasyonlarını gerçekleştiren temel sınıf.
Result / Sonuç Döndürme Deseni:
IResult.cs: Success, Message
IDataResult.cs: IResult'tan kalıtım alır ve generic Data içerir.
Result.cs, DataResult.cs: Temel implementasyonlar.
SuccessResult.cs, ErrorResult.cs: Başarılı/Başarısız işlemler için hazır sınıflar.
SuccessDataResult.cs, ErrorDataResult.cs: Veri taşıyan Başarılı/Başarısız sonuç sınıfları.
Adım 2: Entities Katmanı
Veritabanı varlıkları ve API iletişiminde kullanılacak DTO modellerinin tanımlanması:

Veritabanı Entity'leri (Entities/Concrete/):
Conversation.cs: Id, Title, CreatedAt, Messages (ICollection). IEntity uygular.
Message.cs: Id, ConversationId, Sender, Content, SentAt, Conversation navigation property. IEntity uygular.
Data Transfer Objects (Entities/DTOs/):
CreateConversationRequest.cs: Yeni sohbet açma isteği (Title).
ConversationSummaryResponse.cs: Sohbet listeleme özeti (Id, Title, CreatedAt).
ConversationDetailResponse.cs: Sohbet detay yanıtı (Id, Title, CreatedAt, MessageCount, Participants).
SendMessageRequest.cs: Mesaj gönderme isteği (Sender, Content).
MessageResponse.cs: Mesaj yanıtı (Id, ConversationId, Sender, Content, SentAt).
Adım 3: DataAccess Katmanı
Veritabanı bağlantısı, ORM yapılandırması ve veri erişim sınıflarının yazılması:

Soyut Veri Erişim Arayüzleri (DataAccess/Abstract/):
IConversationDal.cs: IEntityRepository<Conversation> extend eder.
IMessageDal.cs: IEntityRepository<Message> extend eder.
Entity Framework & PostgreSQL Yapılandırması (DataAccess/Concrete/EntityFramework/):
AppDbContext.cs:
DbSet<Conversation> Conversations { get; set; }
DbSet<Message> Messages { get; set; }
OnModelCreating: Tablo isimleri, birincil anahtarlar, yabancı anahtarlar (Conversation-Message ilişkisi: 1-N, Cascade silme), alan uzunlukları ve zorunlulukları (Title max 200, Sender max 100, Content max 2000 vb.).
EfConversationDal.cs: EfEntityRepositoryBase<Conversation, AppDbContext>, IConversationDal implementasyonu.
EfMessageDal.cs: EfEntityRepositoryBase<Message, AppDbContext>, IMessageDal implementasyonu.
Bağlantı Dizesi (Connection String):
MessagingApp.Api/appsettings.json dosyasına PostgreSQL connection string yapılandırması (Host=localhost;Port=5432;Database=messagingapp_db;Username=postgres;Password=...).
Tasks.txt Güncellemesi:

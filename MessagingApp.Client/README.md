# MessagingApp.Client - Terminal Istemcisi Calistirma Talimati

Bu proje, kullanicilarin terminal uzerinden Web API ile haberleserek sohbet odalari acmasini, odalari listelemesini ve polling ile canli mesajlasmasini saglayan konsol uygulamasidir.

## Calistirma Adimlari
1. Once `MessagingApp.Api` projesinin calisir durumda oldugundan emin olun.
2. Terminali bu klasorde acarak su komutu calistirin:
   ```bash
   dotnet run
   ```
3. Uygulama sizden bir kullanici adi isteyecektir.
4. Baglanilacak sunucu adresi olarak varsayilan `http://localhost:5000` adresini (veya yerel agdaysaniz sunucu bilgisayarin IP adresini) girin.
5. Ana menu uzerinden odalara giris yapip mesajlasabilirsiniz.
